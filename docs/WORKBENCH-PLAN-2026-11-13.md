# 2.3 本地工作台实施范围

用户已授权按规划实施，取消语音，并选择先完成本地功能和官方手动核验入口。仓库由用户自行转为 public；本轮只修改本地工程，不发布、推送或改 CI。

## 实施顺序

1. 保持现有 hover 链路、scoreAnalysis、模型和 C2PA 验签不变，新增工作台专用 URL/blob 消息边界。
2. 增加图片右键入口，侧栏/独立工作台共用一个界面；支持文件选择/拖拽、当前网页图片列表、最多 50 项批量排队、停止与重试。
3. 用同一生产证据生成解释，区分模型、未验签声明、可信/不可信/失败签名；官方核验链接不附图、不自动上传。
4. 导出 JSON/CSV：默认不带 URL、不含像素、原始提示词和完整元数据；处理 CSV 公式注入。
5. 三套皮肤为圆环、花瓣、太阳，保留状态语义，提供 26/32/40 像素尺寸、减少动画；补充自动检测暂停域名列表。
6. 运行 Node 回归、Chrome 实际功能验证、旧版完整回归，打包后再次安装验证。测试模拟必须与真实功能验证分别标注。

## 视觉方向

使用项目现有海军蓝底色 #0f172a、面板 #1e293b、正文 #e2e8f0、辅助文字 #94a3b8、交互蓝 #3b82f6；结果状态保留红黄绿灰。系统中文无衬线字体，面板正文 13–14px，标题 18–22px。

工作台以“输入/任务列表”和“选中任务证据”两区组织；窄侧栏上下排列，独立页面宽屏左右排列。任务用连续列表与分隔线表达处理状态，避免把每个字段做成单独卡片。皮肤的花瓣和光芒是唯一装饰重点，不增加无关背景动画。

## 公开影响与验证边界

GitHub API 已核实 public。本地 main 对应的 3 个提交、86 个文本 blob 扫描未命中常见 GitHub/OpenAI/AWS 密钥与私钥格式，不保证识别全部秘密或覆盖远端未获取的分支。未删除文件或重写历史。

现有 MIT 允许按许可复用与商业使用；公开不强制扩展免费，也不撤回已有许可。模型完整版权告知、历史测试图权限仍待核实；本轮不擅自删除样本。隐私、上架、收费和第三方许可是分别处理的事项。

当前模型仍可能漏判：前次 AI 插画为 61 分绿标。新工作台不调整阈值冒充提高准确率，不把签名失败解释为必然篡改。没有可用账号/服务端时，官方接口接入和大模型智能体留作后续明确授权的独立工作。
