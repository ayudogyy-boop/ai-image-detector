# 代码、素材与服务的授权边界

2026-11-12，按项目所有者的选择：保持 GitHub 仓库私有，保留现有 MIT，梳理各类权利；不引入账号、激活码或服务端授权。

## 当前实行的规则

| 对象 | 当前状态 | 实际含义 |
|---|---|---|
| GitHub 仓库 | private | 访问由仓库权限控制。`package.json` 的 `private: true` 只防止误发 npm，不能设置 GitHub 可见性 |
| 本项目代码 | 根目录 MIT | 获得代码的人按 MIT 使用，包括商业使用；私有化不撤回已授予的许可或已分发副本 |
| ORT、C2PA SDK 与依赖 | 各自 MIT / ISC 等告知 | 保留原作者、完整许可和告知，不由本项目 MIT 覆盖 |
| C2PA 信任列表 | CC BY 4.0 原样快照 | 保留来源、日期、署名与许可；不是实时吊销检查或官方认证 |
| 检测模型 | 上游模型卡声明 MIT | 来源和哈希单列在 `models/SOURCES.md`；完整模型版权告知尚待归档，不能以本项目 MIT 替代 |
| SDK 测试图 | 有 MIT 来源记录 | `sdk-c-source.json` 记录来源和哈希；与其余历史图片分别处理 |
| 其他历史测试图片 | 来源/许可记录不完整 | “测试用”不产生再分发权。暂保留供审查，不打入扩展 ZIP；外部分发源码/商业交付前须补齐权限或经所有者同意替换 |
| 品牌、第三方名称与官方入口 | 未新增商标授权 | 不宣称获得厂商背书；不复制 AIHOT 名称、图标、运营数据或服务内容。既有代码许可不因此撤回 |
| 检测结果及未来在线服务 | 当前仅本地计算，没有自营在线服务 | 本地结果没有新设商业许可门槛。未来服务若需商用授权，应另定服务条款，不能用服务条款追溯限制 MIT 代码 |

许可交付清单以根目录 [NOTICE](../NOTICE) 及各组件的来源记录为准。普通构建不联网更新许可、信任列表或模型；包检查会验证这些告知文件存在，并排除评测目录与测试图片。

## AIHOT 参照的准确范围

官方仓库的 [LICENSE](https://github.com/KKKKhazix/AIHOT/blob/d342846e785db3a9a713a869efbc78b9a2dca67c/LICENSE) 是 MIT；[NOTICE](https://github.com/KKKKhazix/AIHOT/blob/d342846e785db3a9a713a869efbc78b9a2dca67c/NOTICE) 单独说明品牌及第三方字体/内容。仓库里的 [条款模板](https://github.com/KKKKhazix/AIHOT/blob/d342846e785db3a9a713a869efbc78b9a2dca67c/site/pages/terms.md) 要求部署者填写自己的运营主体和用途规则，不是现成的商业授权合同。

[AIHOT 官方在线服务规则](https://aihot.news/terms)（查阅时版本 1.1，2026-09-30 生效）允许个人非商业、公益及组织内部用途，对外商业用途需预先取得书面授权。这约束其官方服务和数据访问，不是对其 MIT 源码增设“禁止商用”。管理员登录、会话和 CSRF 则是后台访问控制，也不是付费激活。

本项目借鉴“源码许可、第三方素材、品牌、服务分别说明”的做法，未接入 AIHOT API，也未复制它的条款作为本项目合同。
