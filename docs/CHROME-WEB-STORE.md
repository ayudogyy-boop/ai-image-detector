## 商店文案

名称：Image Authenticity Detector

简短说明：在浏览器本地查看图片 AI 来源线索：模型估计、文件来源声明与 C2PA 核验分层展示，不自动上传图片。

分类建议：工具；默认语言建议：中文（简体）。本版本无付款或订阅功能，不应标为已提供付费升级。

详细说明：

在浏览网页时，悬停图片即可查看来源线索；也可以右键打开图片来源工作台，或拖入自己选择的本地图片。

本扩展分别展示三类依据：本地模型估计、文件中未验签的 AI 来源自述，以及 C2PA 来源凭据核验。它帮助你查看依据，而不是给图片真实性盖章。

主要功能：

- 图片悬停提示、右键入口及侧栏工作台。
- 本地文件选择与拖拽，单图上限 40MB。
- 列出所选网页已加载的图片，最多 50 项串行检测；可停止后续任务、继续和重试。
- 本地导出 JSON/CSV 报告，默认不带图片网址。
- 圆环、花瓣和太阳皮肤，可设置大小、减少动画和暂停自动提示的域名。
- 提供 OpenAI、Google SynthID、Meta 官方手动核验入口，不自动附带图片或网址。

检测在本地进行，不将图片上传到开发者的检测服务。读取网页图片会向原图片服务器发送正常请求；偏好使用 Chrome 同步存储，具体见隐私政策。

模型会误判或漏判。绿色仅表示模型偏非 AI，不证明图片真实；分数不是真实性概率。未检出标识不代表非 AI，签名有效也不证明画面内容属实。专有 SynthID / Content Seal 没有在本地核验。本扩展与所提及的服务商没有隶属或背书关系。

需要 Chrome 116 或更高版本。受限页面、鉴权图片、部分 blob 图片和不支持的格式可能无法读取。

## 隐私与权限填写依据

单一用途：在用户浏览或选择图片时，在浏览器本地查看图片 AI 来源线索，并展示或导出相应证据。

| 权限 | 审核说明 |
|---|---|
| storage | 保存用户检测偏好、圆标外观与暂停域名，以及仅会话保存的右键待办；不保存图片历史。偏好使用 Chrome sync，待办使用 session。 |
| offscreen | 在扩展本地文档中运行打包的 ONNX/WASM 模型、解码图片及核验 C2PA，避免页面生命周期中断分析。 |
| contextMenus | 在网页图片右键菜单提供用户主动检测入口。 |
| sidePanel | 将检测队列与来源证据显示在浏览器侧栏。 |
| 主机访问权限 | 在用户浏览的任意受支持网站上发现图片、绘制提示、列出用户所选页面的图片，并读取跨站图片资源供本地分析。仅 activeTab 无法覆盖任意浏览页面的自动悬停及跨域图片来源。用户可限制站点访问。 |

远程执行代码：没有。扩展自己的 JavaScript、ORT/WASM、C2PA SDK、模型与离线信任列表均随包；下载的是待分析图片，不从远端加载执行代码。外部官方链接仅在用户点击后打开网页。

用户数据披露应与当前表单定义核对：图片/元数据、页面标题及网址在本地处理；偏好（含暂停域名）可经 Chrome 同步；图片服务器接收正常请求；报告由用户主动导出。不应填写“完全不联网”或“没有处理任何网站内容”。本版本没有开发者数据接收服务器、不出售数据、不用于无关目的或信用判断。

## 审核操作说明

无需测试账号或密码。安装后在普通网页将鼠标悬停到已加载的大图；亦可从工具栏打开工作台，选择 PNG/JPEG 等本地文件，点击开始检测。用设置页切换皮肤和暂停域名。报告需在检测完成后点击 JSON 或 CSV 下载。模型冷启动可能需要数秒。模型灰色失败状态、未验签黄色声明和模型红黄绿结果是不同状态。

图标：包内 icons/icon128.png。截图使用真实本地测试界面，合成图案仅用于展示界面，不作为准确率证据；符合商店尺寸的 PNG 放在被忽略的 build/artifacts/workbench-preview/store-workbench-1280x800.png。
