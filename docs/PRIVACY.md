# AI Image Detector 隐私政策

更新日期：2026-11-13。适用于 2.3.0 版本。

本扩展的用途是在浏览器本地提供图片来源线索，包括模型估计、文件来源声明与 C2PA 核验。模型可能误判，检测结果不是对画面真实性的鉴定。

## 图片与网页信息

- 自动提示会在获准运行的网页中查找图片；悬停或主动检测时读取图片地址并下载该图片，字节、模型推理和元数据分析都在本机进行，不上传到开发者或 AI 服务商的检测服务器。
- 读取网页图片仍会向原图片服务器发送正常图片请求，服务器可能看到网络地址及请求信息；这不等于完全不联网。扩展不建立自己的访问日志服务。
- 工作台可列出当前浏览器窗口中受支持的网页标题、网址，以及所选页面中已加载的图片地址，帮助用户选择检测来源。这些信息只在浏览器内使用，不用于分析用户浏览行为或广告。
- 用户选择或拖入的本地图片只在本地读取，不自动上传。扩展不主动读取未被用户选择的本地文件。

## 保存与清理

- 开关、检测选项、皮肤、尺寸、动画和暂停域名等偏好通过 Chrome 的 `storage.sync` 保存。如果 Chrome 同步开启，这些设置可能经 Google 在同一账号的浏览器之间同步；因此暂停域名列表也可能被同步。Google 的处理受其隐私政策与账号设置约束。
- 待处理的右键图片地址仅用 `storage.session` 在当前浏览器会话中暂存，最多 50 项；领取后移除，超过 15 分钟不再领取有效任务，浏览器会话结束时清除。扩展不持久保存检测图片或检测历史。
- 自动提示的临时结果缓存仅保存在页面内存；工作台结果及本地文件引用仅保存在当前界面内存。关闭相关页面可释放这些数据。
- 用户主动导出 JSON/CSV 时，报告会保存到用户的下载位置。默认不带图片网址，不含图片像素、完整元数据或原始提示词；用户可主动勾选网页图片网址。文件名、检测时间、结果及有限证据可能包含个人信息，分享报告前请自行检查。报告的保留与删除由用户控制。
- 卸载扩展可移除扩展存储；已下载的报告需另行删除。设置中的恢复默认可重置偏好。

## 第三方入口

OpenAI、Google SynthID 和 Meta 的核验链接只在用户主动点击时打开，不自动附带图片、图片网址或当前页面网址。用户随后自行选择上传时，适用相应服务商的条款与隐私政策，文件将由该服务商处理。

本版本没有开发者运营的账号服务、云端智能体、遥测、广告、支付或订阅系统；不将用户数据出售、用于广告、训练模型或判断信用资质。

本扩展对用户数据的使用遵守 Chrome Web Store 用户数据政策及其 Limited Use 要求，仅用于上述单一功能。

## 权限用途

- 网页访问权限：发现图片、显示提示、按用户操作列出图片并读取用于本地分析的图片。支持跨域图片来源；用户可在 Chrome 中限制站点访问，也可在扩展设置中暂停指定域名的自动提示。
- `storage`：保存偏好及当前会话的右键待办。
- `offscreen`：在受控的本地扩展文档内解码图片、运行随包模型并核验来源信息。
- `contextMenus`：提供图片右键检测入口。
- `sidePanel`：显示图片来源工作台。无法打开侧栏时使用扩展自己的独立页面。
