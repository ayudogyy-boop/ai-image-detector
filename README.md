# Image Authenticity Detector

Chrome 扩展，在本地查看图片的 AI 来源线索。当前版本 **2.2.1**。

悬停图片后显示徽章，点击查看依据。图片不会上传给检测服务；官方水印核验入口需要你自行选择并上传文件。

## 如何理解结果

| 显示 | 含义 |
|---|---|
| 已验证 AI 生成/编辑声明 | C2PA 完整资产及签名验证通过，签发方在随包离线信任列表中，当前清单含明确 AI 动作 |
| 含 AI 来源声明（未验签） | 检出了生成参数、工具字段、IPTC 或 AIGC 标识；文件自述可伪造，不等于已验证 |
| 签名有效，来源未受信任 | 签名与资产绑定有效，但签发方未获当前信任列表认可 |
| 模型疑似 AI / 模型偏非 AI | 本地模型的统计估计，不是水印检测或真实性证明 |
| 无法确定 | 模型分数处于 40–60 的不确定区间 |
| 灰色“—” | 检测未完成或模型已关闭；点击查看具体阶段、错误及扩展版本，不表示图片属于 AI 或非 AI |

**没有水印不等于真实；有效相机签名也不保证画面内容属实或从未编辑。** 显示的分数是模型展示值，不是校准后的真实性概率。绿标仅表示模型偏非 AI。

模型分数固定按以下区间着色：**低于 40 红色、40–60 黄色、高于 60 绿色**，40 和 60 均为黄色。旧灵敏度设置不再改变这些边界。未验签声明不会把低分红标改成黄色；没有可用模型结果或独立来源声明时显示灰色未完成，不生成占位 50 分。

2.2.1 修复了模型首次加载失败后不恢复、元数据成功时把模型失败缓存十分钟的问题。模型加载按需重试并限制频率，推理运行时失效后下次请求会重建；图片解码错误单独报告。点击灰色徽章可区分 HTTP 拒绝、超时、文件过大、解码、模型加载与推理错误，页面统计独立列出未完成图片。

## 本地支持的证据

- **C2PA**：使用官方 `@contentauth/c2pa-web` 0.16.0 验证整张图片，区分可信、有效但未受信任、无效、未发现、无法核验。只解释当前 active manifest 的受控 AI 动作，不扫描品牌词来冒充验签。
- **PNG**：未压缩/压缩文本、SD 生成参数组合、ComfyUI 采样器节点结构；文本解压总量最多 1MB。
- **JPEG / WebP**：EXIF、XMP、JPEG 注释与 APP11 AIGC 声明；PNG 和 XMP 中的国内 AIGC 标识也可读取。Label 1、2、3 保持不同语义。
- **ONNX 模型**：保留原有本地 ViT，设置中可关闭。未验证的相机元数据及不存在的 C2PA 不再给模型分数加权。

相机/软件字段只作参考。普通描述提到 Midjourney、普通节点图含 nodes 等均不直接判 AI。

## 专有像素水印

扩展**没有本地 SynthID 或 Content Seal 检测器**。设置页和徽章详情提供官方手动核验入口：

- [OpenAI Verify](https://openai.com/verify)
- [Google SynthID Detector](https://synthid.com/)
- [Meta Content Seal](https://www.meta.ai/identification/)

打开入口不会自动传图片、图片 URL 或页面信息。由你自行决定上传；第三方服务的处理方式由其政策决定。

厂商水印与 GitHub 项目对照、实现选择和实测结果见 [本轮调研记录](eval/PROVENANCE-RESEARCH-2026-11-10.md)。

## 安装与使用

1. 打开 `chrome://extensions`，启用开发者模式。
2. 点击“加载已解压的扩展程序”，选择本目录或 ZIP 的解压目录。
3. 悬停图片，默认 3 秒后分析；点击徽章查看证据。
4. 点击扩展图标查看当前页面统计，进入设置可调延迟和信号开关，并查看分数颜色规则。

需要 Chrome 116+。设置即时生效。触摸/窄屏自动检测仍只处理初次可见的前 10 张图片，完整手机交互是后续工作。

## 隐私与资源限制

- 所有模型与验签组件随扩展打包，不使用运行时 CDN，不向云端上传图片。
- C2PA 必须读取完整图片校验资产绑定；模型或 C2PA 开启时最多下载 40MB，超限或断流明确降级。
- 只开文件元数据时读取前 512KB；超出窗口的后置字段可能漏检。
- 全局最多同时分析两张图；推理串行。超大像素图的解码内存仍需注意。
- 验签只用随包官方信任列表快照，不请求远端清单或在线 OCSP 吊销状态；新签发方、旧证书和远端清单可能无法核验。

## 模型能力

现有 ViT 在本项目 240 张旧评测图上 AUC 约 **0.653**。样本包含老生成器和非摄影作品，不能代表现代生成器的检测准确率。此次升级加强来源验证和结果解释，没有重训或换掉模型。
